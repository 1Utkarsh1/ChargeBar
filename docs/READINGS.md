# Battery readings and limits


- **Estimated charge (≈):** the menu bar, large panel number and progress bar use macOS's percentage as their baseline, with predicted decimals between updates. The system's 0% and 100% readings take effect immediately, including while unplugged or when fine capacity is missing. A raw capacity ratio of 94.59% no longer prevents the main display from showing 100.00% when macOS reports 100%. Charging status still comes from macOS. Two decimal places are an estimate, not measurement accuracy of 0.01%.
- **Underlying prediction:** starts at the macOS battery level when available, then integrates valid signed current over elapsed time using full-charge capacity. It prefers instant current over averaged current. Changes in the raw capacity ratio do not reset a system-backed prediction; a new system level is reconciled over a few seconds. Between system endpoints, corrections cannot increase an unplugged/draining estimate or decrease one with positive charging current. Prediction continues beyond 60 seconds while current is valid and is bounded to two percentage points of disagreement with its selected baseline, with a "Waiting for battery gauge…" label at the limit. Larger opposing baseline recalibrations hold the previous value until the baseline catches up. A long polling gap refreshes the time anchor while preserving direction. System sleep, an app restart, a complete data outage or a change between system and raw fallback sources starts a fresh baseline.
- **Raw fallback:** if macOS's level is unavailable but fine capacity is valid, the earlier raw prediction and +1 percentage point display adjustment are retained, capped at 100%. For example, 56.89% becomes ≈57.89%. This preference can show 100% before physical full charge. Before fine capacity is obtained, the whole system level is shown without prediction. Brief loss of fine capacity holds the last estimate for up to three seconds, then falls back to the whole system value; known system endpoints override that waiting period.
- **Raw battery gauge:** remaining capacity divided by full-charge capacity, shown separately without prediction. Hardware publishes these values in steps; reading faster cannot force new sensor data.
- **macOS battery level:** the operating system's rounded battery level. It may differ from the raw estimate because macOS applies its own battery presentation rules.
- **Into/from battery:** battery power telemetry in watts, with voltage times signed current as a fallback. During a cable transition, stale current or power with the wrong sign is withheld until a compatible reading arrives. The connection icon and state update independently of this electrical settling time.
- **Power into Mac:** live adapter input telemetry, including energy used to run the computer. This differs from battery charging power.
- **Charger capacity:** the adapter's reported capacity for its current connection. This is a limit, not the actual live charging rate.
- **Until full:** the system estimate, shown only while charging. It may change with workload and charge management.
- **Battery time left:** estimated time until the battery runs out, shown in the panel and menu bar tooltip. It prefers the macOS time-remaining estimate while discharging. If unavailable, it calculates `remaining mAh ÷ discharge mA × 60` minutes from the reported battery current. It uses raw capacity, without the +1 display adjustment. Charging shows "Charging", external power without measurable drain shows "Not draining", and missing/near-zero discharge data shows "Calculating…". A weak adapter that still allows battery drain also gets a runtime estimate. Workload, reserve capacity and battery condition can change the result; low-battery sleep or shutdown may happen sooner.

Before a decimal estimate is obtained, missing decimal capacity falls back to the whole system percentage; after that, it holds the last estimate and labels the missing gauge for up to three seconds before falling back. Missing power readings appear as unavailable. A transient read failure holds the last value for up to three seconds and labels it "Waiting for battery data…"; a longer failure clears it. A subsequent successful poll or power notification restores it automatically. The IORegistry diagnostic keys can change in a future macOS release; this build was checked on the owner's current Mac. No charging limits or power settings are changed.
